# Blade CS2 Internal Base - Information
Blade is a lightweight CS2 internal base focused on ESP-only visuals.
It hooks DXGI Present (D3D11), runs a simple ImGui menu (Insert), and gives you a clean SDK-style layout to build player ESP on top of.
Built for learning and as a starting point for CS2 internals — not a full cheat pack.

# Features
- DX11 Present / ResizeBuffers overlay hook
- ImGui menu with Tahoma font
- Insert toggle
- Watermark
- ESP-ready SDK layout (`C_BaseEntity`, `C_CSPlayerPawn`, `CCSPlayerController`, `CGameSceneNode`)
- Intended for box ESP / health / name using `dwViewMatrix` + entity list
